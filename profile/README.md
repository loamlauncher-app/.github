### 🏛️ The Design Philosophy

LOAM was built as a direct response to bloated, ad-heavy, and resource-intensive launchers. Three core pillars guide every decision:

- **Calm Interface:** Swiss-minimalist layout — warm paper-and-ink palette, generous whitespace, and precise Geist typography.
- **Absolute Isolation:** Every game directory and modpack is sandboxed to prevent file pollution and conflicting version caches.
- **Performance First:** Built with **Tauri 2 and Rust**, delivering fast cold-starts and a minimal RAM footprint on Windows 10/11 x64.
